## 1. 定位与与 Plan A 的关系

Plan B′ 是与 Plan A（stage0 → stage1 → stage2 解析管线）并行互补的**学习式方案**。本项目不使用教师模型蒸馏——训练信号完全来自**可微碰撞代价**（§4），无任何位姿标签：

| 角色 | 承担方 | 说明 |
|---|---|---|
| 判定器（训练 + 推理统一） | 可微碰撞代价函数（§4） | 运动学级 EEF–物体刚体碰撞；训练时为损失，推理时阈值化为成败判定 |
| 快速推理前端 | 本方案的条件生成网络 | 单次前向替代 stage0 搜索 + stage1 解析计算 |
| 冷启动锚点 | 标称系 $T_{nom}(\hat{a})$ + 零初始化输出头 | 网络初始输出 = 解析标称位姿（§3.1） |
| 可选离线抽检（不在管道内） | Plan A 的 stage2 | 动力学级验收工具，仅离线评估用，不进入训练回路 |

**已明示的取舍**：判定降级后，滑落 / 重心不稳 / 动态扰动**失去直接检测能力**，仅剩几何代理缓解（§4.4 摩擦锥判据 + 对称接触 + 接触窗口）。此为本方案的核心边界，记录于 §9。

### 1.1 对原始 Plan B 的四处修正

| 原方案 | 问题 | 修正 |
|---|---|---|
| (1) 单峰回归输出 | 多模态平均陷阱：两个好抓取的平均是坏抓取 | **多假设生成头**（条件扩散 / MDN） |
| (2) 可微运动学模型用神经网络 | 学已知的解析关系：近似误差毒化梯度、训练成本、不可解释 | **可微解析层**（stage1 公式 PyTorch 化，零训练、精确） |
| (3) 动力学 loss 端到端回传 | 接触力读数与离散成败不可微 | **判定降级（v1.3）**：运动学碰撞代价全可微，单一链路端到端 |
| (4) teacher 蒸馏 warm-start | 项目决策不采用 | 零初始化输出头 + SDF 引导课程（§5.1） |

核心数据流约定：

- 复用 stage1 的**切空间参数化**（$\boldsymbol{\xi} = (\Delta t, \Delta R) \in \mathbb{R}^6$，平移在前）；
- 所有计算在规划参考系 {W} 下统一；物体几何先规范到 {O} 系，代价计算时变换回 {W}；
- 输出多假设按代价升序交付，Top-K 语义与 stage0 一致。

## 3. 网络设计

### 3.1 输出参数化与冷启动

- **标称系 $T_{nom}(\hat{a})$**：由 â + 截面基解析构造（物体几何中心投影 + 名义深度），不依赖任何学习组件；
- **网络输出规格（v1.3.3 明确）**：给定条件 $c$，网络交付量为每假设二元组 $(\hat{\boldsymbol{\xi}}_k \in \mathbb{R}^6,\ \Delta\hat{q}_k \in \mathbb{R})$，$k = 1..K$：
  - **位姿映射（与 stage1 §4.1 扰动约定完全一致）**：右扰动 / body 系，$T_{TCP,k} = T_{nom}(\hat{a}) \cdot \exp(\hat{\boldsymbol{\xi}}_k^{\wedge})$；exp map 实现须含小 $\|\Delta R\|$ Taylor 分支防 $\omega \to 0$ 处 NaN，$\|\Delta R\| = \pi$ 处雅可比退化为零测奇异；
  - **分量语义**（$(\boldsymbol{v}, \boldsymbol{\omega})$ 顺序 = (平移, 旋转)，body 系三轴）：$[\Delta x, \Delta y, \Delta z]$ = 沿 $\vec{X}_e / \vec{Y}_e / \vec{Z}_e$ 平移（$\vec{Z}_e \parallel \hat{a}$：$\Delta z$ = 沿接近方向深度微调，$\Delta x / \Delta y$ = 垂直 â 平面内偏移）；$[\Delta\alpha, \Delta\beta, \Delta\gamma]$ = 绕三轴旋转（$\Delta\gamma$ = Roll，$\Delta\alpha / \Delta\beta$ = Pitch / Tilt）；
  - **归一化（扩散噪声空间）**：$\boldsymbol{\xi}$ 以尺度向量 $\mathbf{s}_{\xi} = [s_p, s_p, s_p, s_r, s_r, s_r]$ 归一化后进入扩散过程（初始 $s_p$ = 1 cm、$s_r$ = 0.1 rad）——平移与旋转量纲不同，不归一化会使 DSM 噪声调度偏置大量纲分量；采样后反归一化再作 exp 映射；
  - **开度输出**：$q_{open,k} = w_{obj}(T_{TCP,k})/2 + \delta_{hi} + \Delta\hat{q}_k$——闭式项按各假设位姿的截面宽度计算（§5.3），网络只学残差 $\Delta\hat{q}$；
- **零初始化输出头**：扩散头 $x_0$-prediction 与 $\Delta q$ 残差头最后一层均零初始化——训练开始时 $\hat{x}_0 = 0,\ \Delta\hat{q} = 0$，采样输出恒为 $T_{nom}(\hat{a})$ + 闭式开度（解析级粗对齐质量），碰撞代价从第一步起即有梯度；
- **生成头**：条件扩散头（DDPM/DDIM，$\boldsymbol{\xi}$ 为噪声空间）；备选 MDN（消融）。K 次采样天然覆盖多模态。

### 3.2 几何编码

- **物体（v1.3.4 决策：优先基元参数直接嵌入）**：输入 = 参数向量（盒 $W \times L \times H$ / 圆柱 $(r, h)$ / 球 $(r)$）+ 可学习类型 token（每类 8 维）；尺度预处理用 $\log(p)$ + LayerNorm 或 NeRF 式 Fourier 特征（参数扫描跨数量级，线性输入区分度不足）；2–3 层 MLP → 256 维条件向量。确定性、零采样方差、微秒级成本，且参数是基元的充分统计量（条件 ↔ 代价 $D_O$ 近同构）；
- **点云 encoder：预留接入，暂不实施**：条件接口 $c \in \mathbb{R}^{256}$ 与编码器实现解耦（扩散头只消费 256 维条件 + 类型 token）——后续纳入 mesh 物体时以独立点云塔（PointNet++ / set attention，$N \approx 512$–$1024$，{O} 系规范姿态，带采样一致性正则）映射进同一条件空间即可，上游零改动；触发条件：mesh 库（ABC）进入训练集（§6）；
- EEF：参数化几何（$G_{EEF}$：指厚/指长/开度范围/掌部）固定嵌入；
- 噪声增广与 stage0 §7 感知误差模型一致。

## 4. 可微碰撞代价（本方案核心）

**判定规则**：EEF 与目标物体的刚体碰撞状态——具体为**指垫受控接触 + 非接触面防撞**的结构化代价。实现参考 DiffPhyRobot 的梯度绕行模式（env_robot_2d.py `find_vec_to_obstacles`）。

### 4.1 梯度链路（DiffPhyRobot 模式映射）

| DiffPhyRobot（避障） | 本方案（抓取） | 可微性 |
|---|---|---|
| 机器人检测点（步态剖面 `_gait_profile_positions`，torch 可微） | **EEF 指垫采样点** $p_{f,j} = \mathrm{FK}(T_{task}, q_{open})$——解析运动学直出，可微 | ✓ 梯度流经 $T_{task}$ 回网络 |
| 障碍物表面最近点（quadrants kernel `find_nearest_pt_2d_topk`，detached） | **物体表面最近点 / SDF 查询**（基元闭式 SDF 或 mesh kernel oracle） | ✗ 视为局部常数（一阶近似） |
| 碰撞向量 `npt − p` → 避障惩罚 | 采样点–表面距离 → **接触窗口** / **防撞惩罚**（语义反转） | ✓ |

**基元物体**（盒/圆柱/球）：闭式 SDF（圆柱 `‖p−c‖−r`、盒分象限，同 DiffPhyRobot `_clearance_to_obstacles` L69-97 的形式），挂上 autograd 即全可微，**无需 kernel**。
**Mesh 物体**：预计算 SDF 场（三线性插值，分段线性 C⁰——单元内常值梯度、单元边界 kink，a.e. 可微且无死梯度）或 quadrants 最近点 oracle（表面点 detach，梯度只走查询点）。**非凸 mesh 慎用 oracle**：查询点跨越中轴时最近表面点跳变，"固定投影点"假设的梯度方向可产生 O(1) 误差（超出光滑面上的一阶近似范畴）——非凸物体优先预计算 SDF 场，oracle 仅限凸/近凸 mesh。

### 4.2 代价项

设指垫内侧采样点集 $\{p_{f,j}^{L}\}, \{p_{f,j}^{R}\}$（每指 $n_p$ 个），非接触面（指背/指侧/掌部）采样点集 $\{p_{b,k}\}$，物体 SDF 为 $D_O(\cdot)$（负值 = 内部），场景 SDF 为 $D_S(\cdot)$（v1.3.2 新增：桌面平面闭式 + 可选场景物体，仅用于走廊防撞）。**接触斑** $\mathcal{C}_{L/R}$ = 每指距离最近的 $n_c = \lceil q_c \, n_p \rceil$ 个指垫点（top-k 选择，对被选值可微）：

| 项 | 公式 | 语义 |
|---|---|---|
| **接触窗口** | $\mathcal{L}_{touch} = \overline{\mathrm{relu}(D_O(p_{f,j}) - \delta_{hi}) + \mathrm{relu}(\delta_{lo} - D_O(p_{f,j}))}$（平均域 $j \in \mathcal{C}_L \cup \mathcal{C}_R$，接触斑） | 接触斑内的点落在 $[\delta_{lo}, \delta_{hi}]$（如 [0, 2mm]）为零罚。**分位数口径（v1.3.2）**：仅要求接触斑（每指最近 $q_c$ 比例点）在窗口内——消除平垫贴曲面的损失地板（角点翘起不罚）；训练零损失 ⇒ $D_{min} \in$ 窗口（推理条件 1 仍被蕴含）；被选集外的点自动满足 $D \ge \delta_{lo}$（无穿透） |
| **双侧对齐** | $\mathcal{L}_{2s} = \mathrm{relu}(D_{min}^{L} - \delta_{hi}) + \mathrm{relu}(D_{min}^{R} - \delta_{hi})$ | 双指都必须有接触（$D_{min}$ = 该指所有采样点最小距离） |
| **对称接触** | $\mathcal{L}_{sym} = \overline{\lVert D_O(p_{f,j}^{L}) - D_O(p_{f,j}^{R}) \rVert}$ | 两指穿透深度均衡（力矩平衡的几何代理） |
| **接触高度差** | $\mathcal{L}_{hgt} = \mathrm{relu}(\lvert h_{L} - h_{R} \rvert - h_{max})$ | 双指 $D_{min}$ 接触点沿指长方向（垂直于开合轴 $X_e$）的坐标差受限（力闭合代理，§4.4） |
| **质心对齐** | $\mathcal{L}_{com} = d_{\perp} + \ell \cdot \left[\mathrm{relu}(m_{seg} - s) + \mathrm{relu}(s - 1 + m_{seg})\right]$ | 质心投影落入接触线段（带边距，v1.3.6 细化）：$s$ = 质心投影 $c_{com}^{\perp}$ 在 $p_{L}^{*} \to p_{R}^{*}$ 上的线段参数（$s=0$ 在 $p_L^*$，$s=1$ 在 $p_R^*$），$d_{\perp}$ = 质心投影到接触连线的垂距，$\ell$ = 线段长（取下限 clamp 防退化）。原中点对齐为 $s = 0.5$ 特例；新形式允许不对称但稳定的抓取，只罚垂距与边距越界（§4.4；质心为 detached 常数，梯度流经接触点） |
| **软对向** | $\mathcal{L}_{anti} = \mathrm{relu}(\hat{\theta}_{opp} - \theta_{max})$ | 训练侧对齐推理判据（v1.3.2）：$\hat{\theta}_{opp}$ 由可微接触点连线与指面法向计算（表面法向 detached，梯度流经接触点），消除"训练零损失但推理拒判"的边缘/同面假盆 |
| **走廊防撞** | $\mathcal{L}_{cor} = \overline{\mathrm{relu}(\delta_{clear} - \min(D_O(p_{b,k}),\, D_S(p_{b,k})))}$ | 非接触面与**物体及场景**（桌面等，v1.3.2 纳入）保持间隙——与 DiffPhyRobot 避障代价同构 |
| **开度合法** | $\mathcal{L}_{w} = \mathrm{relu}(q_{open} - q_{max}) + \mathrm{relu}(q_{min} - q_{open})$ | 手指开度在工作行程内 |

**推理期判定（阈值化，非训练损失）**：

$$\text{success} = \left( D_{min}^{L}, D_{min}^{R} \in [\delta_{lo}, \delta_{hi}] \right) \wedge \left( \theta_{opp} \le \theta_{max} \right) \wedge \left( \min_k \min(D_O(p_{b,k}), D_S(p_{b,k})) \ge \delta_{clear} \right)$$

$\theta_{opp}$ = 两指接触点连线与指面法向的夹角（对向性）。

### 4.3 接近过程建模（准静态推进）

抓取是过程不是单帧：从 $T_{task}$ 沿 $-\hat{a}$ 回退 $\ell_{retreat}$ 的**扫掠检查**——指垫采样点沿接近路径积分采样（$n_\ell$ 个中间构型），走廊代价取路径最大值。纯几何积分，可微。

### 4.4 动力学 gap 的几何缓解（先验，非验证）

| 失去的能力 | 几何代理 | 接入方式（v1.3.1 明确，v1.3.2 补 $\mathcal{L}_{anti}$） |
|---|---|---|
| 摩擦保持（滑落） | 摩擦锥几何判据：对向法向夹角 $\le \pi - 2\arctan(\mu)$（µ 为先验，保守取 0.5） | 推理判定 + 训练损失（v1.3.2）：$\theta_{opp} \le \theta_{max}$ 推理判据 + 软约束 $\mathcal{L}_{anti}$（§4.2，与 stage0 θ_fric 同源） |
| 力闭合 | 对向双侧接触 + 对称穿透 + 接触点高度差 | 训练损失：$\mathcal{L}_{2s}$ + $\mathcal{L}_{sym}$ + $\mathcal{L}_{hgt}$（§4.2，均可微） |
| 提升稳定（重心） | 质心投影落入接触线段（带边距）+ 垂距最小化（质心由几何估计；中点对齐为 v1.3.5 前特例） | 训练损失：$\mathcal{L}_{com}$（§4.2，v1.3.6 细化为线段内判据，可微；质心为 detached 常数，梯度流经接触点） |

这些是**先验假设而非检测**——若实际 µ 更低或物体内部质量分布异常，本方案无法发现（§9 风险 R1）。

## 5. 训练流程（全可微，无仿真在环）

### 5.1 阶段 T1：碰撞代价从零训练

- **初始化**：零初始化输出头（初始网络输出 = $T_{nom}(\hat{a})$）；
- **DSM 伪数据机制（v1.3.2 定义，替代缺失的位姿标签）**：周期性用当前模型 DDIM 采样 $K$ 个假设 → 代价阈值过滤 → 通过者作伪标签 $\xi^{+}$ 参与 $\mathcal{L}_{DSM}$（best-of-K 自蒸馏；离散过滤在数据层，梯度链路不受影响）；失败样本由 T3 回流补充对比项；
- **课程**：
  - **C0（SDF 引导）**：$\mathcal{L}_{guide} = \overline{|D_O(p_{f,j})|}$——**绝对距离（v1.3.2 修正：原 signed 形式的全局最优是最大深度嵌入而非表面接触）**，两侧均吸向表面、远场处处有梯度；
  - **C1（粗对齐）**：$\mathcal{L}_{guide} + \mathcal{L}_{cor} + \mathcal{L}_{2s}$；
- **损失**：$\mathcal{L}_{DSM}(\xi^{+}) + \lambda_{geo} \cdot \mathcal{L}_{C0/C1}$（几何代价挂在 $\hat{x}_0$ 单步估计上）；
- **多模态**：扩散框架对"碰撞代价低的位姿集合"建模，多模态由采样噪声探索 + 代价地形隐式给出。

### 5.2 阶段 T2：全约束端到端精调

- **损失**：$\mathcal{L}_{DSM}(\xi^{+}) + \lambda_{geo} \cdot (\mathcal{L}_{touch} + \mathcal{L}_{2s} + \mathcal{L}_{sym} + \mathcal{L}_{cor} + \mathcal{L}_{w} + \mathcal{L}_{hgt} + \mathcal{L}_{com} + \mathcal{L}_{anti})$（权重见 §12）；
- **作用**：接触窗口精调 + 扫掠走廊检查（§4.3）全部进入计算图；
- **短链一致性（v1.3.2）**：每 $N_{sc}$ 步叠加 2–3 步可微 DDIM 短链上的几何代价，弥合 $\hat{x}_0$ 单步训练与 10 步采样推理的分布偏差。

### 5.3 阶段 T3：开度联合精调 + 失败回流

- **开度 $q_{open}$ 联合优化**：作为可微变量与位姿联合训练（初始闭式：$q_{open} \approx w_{obj}/2 + \delta_{hi}$；$w_{obj}$ 为**沿开合轴 $X_e$ 的截面宽度——位姿相关量**，v1.3.2 明确：由物体采样点沿 $X_e$ 投影 extent 的 max/min 计算，可微，随位姿重算）——替代 stage2 的手指力精调；
- **失败回流（DAGGER）**：推理期判定失败的四元组 `(输入条件, 位姿假设, 失败原因, 诊断量)` 回流训练集——失败原因含 `no_contact`（窗口过浅）/ `hard_collision`（穿透过深）/ `corridor_violation`（防撞失败）/ `not_antipodal`（对向角超限），以对比项进入回归目标；
- **可选离线抽检**：每隔 N 个 epoch 用 stage2（Genesis 前向）对 held-out 样本做动力学抽检，**仅作监控指标**（如滑落率），不产生训练梯度——保留动力学 gap 的可观测性而不增加在线成本。

## 6. 数据管线（纯几何自监督，无标注无仿真）

| 环节 | 设计 |
|---|---|
| 物体来源 | **v0（v1.3.4）：基元参数扫描（长方体/圆柱/球），总量 $\sim 10^4$**；mesh 库子集（如 ABC）随点云塔（§3.2 预留）接入后再纳入 |
| 方向采样 | 每物体 $\sim 10$ 个 $\hat{a}$（半空间均匀 + 偏置） |
| 训练信号 | 碰撞代价自监督（§4）+ 自采样伪标签（§5.1，v1.3.2）——**无需外部位姿标签、无需仿真打分** |
| 增广 | {O} 系规范姿态对齐、对称类标签（解析）、点云扰动（与 stage0 §7 一致） |
| 成本 | 每步 = 网络前向 + 解析运动学 + SDF 查询——GPU 批量，吞吐高于仿真在环一个量级 |

## 9. 风险与缓解

| 风险 | 缓解 |
|---|---|
| **R1 动力学 gap 无验证器兜底**（滑落/重心/扰动不可检，判定降级的直接代价） | 摩擦锥几何判据（µ 保守先验）+ 对称接触 + 质心对齐（§4.4）；T3 可选 stage2 离线抽检监控滑落率；上线前用 stage2 做一次全量离线验收 |
| R2 碰撞代价的局部极小（贴面不接触 / 单侧接触） | C0 SDF 引导 + 多假设 K 采样 + 失败回流对比项 |
| R3 多模态平均 | 扩散头多假设；代价地形隐式多模态 |
| R4 冷启动零梯度 | 零初始化（初始 = 标称位姿）+ SDF 引导远场梯度 |
| R5 Mesh 物体的 SDF 预计算成本 | 基元场景闭式 SDF 零成本；mesh 离线预计算一次复用；oracle kernel 兜底 |
| R6 开度–位姿耦合的非凸性 | 开度闭式初始化（物体宽度先验）+ 联合微调 |
| R7 自采样伪数据的确认偏置 / 模式坍缩（v1.3.2 新增） | 采样噪声探索 + 失败回流对比项 + §10 多假设有效率指标监控 |

## 10. 验收

| 指标 | 定义 | 目标 |
|---|---|---|
| Top-K 通过率 | K 个假设中 ≥1 个通过运动学判定 | ≥ 90%（基元集）；held-out ≥ 80% |
| Top-1 通过率 | 首假设通过率 | ≥ Top-K 的 70% |
| 推理延迟 | 网络前向 + 解析层 + 代价计算（GPU） | ≤ 50 ms |
| 泛化衰减 | held-out 物体集相对训练集的下降（v0 = 基元参数 held-out；mesh 随点云塔启用） | ≤ 10 个百分点 |
| 冷启动基线 | 零初始化网络（= 标称位姿）的判定通过率 | > 0（验证 $T_{nom}$ 质量） |
| 多假设有效率（v1.3.2） | $K$ 个假设中可分辨模式数（两两 SE(3) 距离超阈值视为可分辨；模式坍缩检测，对应 R7） | ≥ 2 |
| **动力学抽检（离线监控，非验收线）** | stage2 前向验证的运动学通过样本滑落率 | 记录并趋势下降；无硬阈值（R1 取舍的量化观测） |
| 代价–梯度保真 | 代价函数对位姿的 AD/FD 交叉验证 | ≥ 0.99（纯解析链路应接近精确） |

## 11. 方法选型总结

| 设计点 | 选择 | 放弃方案及其失败模式 |
|---|---|---|
| 判定规则 | 运动学可微碰撞代价（§4） | 动力学级判定（需 Genesis 在环，工程重、吞吐低——已按项目决策降级） |
| 碰撞代价实现 | 基元闭式 SDF + mesh SDF/oracle（DiffPhyRobot 梯度绕行模式） | mesh-mesh 精确碰撞（不可微或代价过高） |
| 输出头 | 条件扩散多假设 | 单峰回归（多模态平均陷阱） |
| 运动学 | 可微解析层 | 神经网络学习（近似误差毒化梯度） |
| 训练信号 | 碰撞代价自监督 + 自采样伪数据（无外部标签无仿真，v1.3.2） | teacher 蒸馏（已决策不采用）；仿真打分回归（依赖 Genesis，v1.3 已移除） |
| 冷启动 | 零初始化 + SDF 引导 | 纯 hinge 从零（远场零梯度） |
| 开度 | 闭式初始化 + 联合微调 | 固定开度（对宽度变化不鲁棒）；力控仿真精调（依赖 Genesis） |
