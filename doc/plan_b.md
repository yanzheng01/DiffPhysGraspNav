# Plan B′：学习式抓取位姿生成方案

**版本**：v1.0（起草稿，待评审）
**日期**：2026-09-23
**上游依赖**：stage0.md（约束体系与失败闭环协议）、stage1.md（位姿分布与切空间参数化）、stage2.md（可微抓取检测器与 Genesis 1.3.3 实测约束）

## 1. 定位与动机

### 1.1 与 Plan A 的关系

Plan B′ **不是 Plan A（stage0 → stage1 → stage2 解析管线）的替代**，而是 teacher–student 混合架构：

| 角色 | 承担方 | 说明 |
|---|---|---|
| Teacher（数据引擎） | Plan A 的 stage0 + stage1 | 批量生成带分布参数的位姿标签 |
| 验证器（兜底判定） | Plan A 的 stage2 | 动力学级成功判定（力阈值 + 提升确认），不可微、仅前向 |
| Student（快速推理前端） | 本方案的条件生成网络 | 单次前向替代 stage0 搜索 + stage1 解析计算 |

**收益场景**：任意形状物体（无解析基元）、在线推理延迟约束、需要分布/多假设输出。若任务仍是已知几何的桌面抓取，Plan A 全解析路径的成本收益比占优——Plan B′ 的立项前提是上述至少一项成立。

### 1.2 对原始 Plan B 的三处修正

| 原方案 | 问题 | 修正 |
|---|---|---|
| (2) 可微运动学模型用神经网络 | 学已知的解析关系：近似误差毒化梯度、训练成本、不可解释 | 改为**可微解析层**（stage1 公式 PyTorch 化，零训练、精确） |
| (3) loss 端到端回传优化 | 动力学 loss 需仿真在环，而 Genesis 1.3.3 初始位姿无梯度路径（§7） | 拆分：几何 loss 端到端 + **采样–打分–回归**闭环（仿真仅前向） |
| (1) 单峰回归输出 | 多模态平均陷阱：两个好抓取的平均是坏抓取 | **多假设生成头**（条件扩散 / MDN） |

## 2. 总体架构

```
                     ┌──────────────────────────────────────────┐
                     │              推理（部署）路径              │
                     └──────────────────────────────────────────┘
 EEF 参数 e ──────┐
 物体点云 P_O ────┤   ┌────────────┐   K×ξ̂   ┌──────────────┐  K×T_task
 近进方向 â ──────┼──▶│ 条件生成网络 │───────▶│ 可微解析运动学层│────────▶ stage1 式预检
                  │   │  (§3.1)    │  (切空间) │    (§3.2)    │  (硬筛)      │
                  │   └────────────┘          └──────────────┘             ▼
                  │                                          stage2 仿真判定（前向）
                  │                                          (GraspDetector + 提升确认)
                  │                                                       │
                  │                                              首过执行 / 全败回传
                  └─────────────── 失败样本回流（§3.4）◀──────────────────┘

                     ┌──────────────────────────────────────────┐
                     │              训练（离线）路径              │
                     └──────────────────────────────────────────┘
 T1: teacher 蒸馏 warm-start（§4.1） ──▶ T2: 几何代价端到端精调（§4.2）
                                          └──▶ T3: 采样–打分–回归闭环（§4.3，stage2 在环）
```

核心数据流约定：

- 网络输出与分布建模**复用 stage1 的切空间参数化**：扰动向量 $\boldsymbol{\xi} = (\Delta t, \Delta\varphi) \in \mathbb{R}^6$（平移在前），经指数映射合成位姿——扩散噪声空间与 stage1 的扰动空间完全同构；
- 所有几何量在 $\{O\}$ 系表达（与 stage0.md §2.2、stage1.md §2.2 的接口约定一致），进入解析层后统一变换至 $\{W\}$ 系计算。

## 3. 模块设计

### 3.1 条件生成网络

**输入编码**：

| 输入 | 编码 | 维度 | 说明 |
|---|---|---|---|
| EEF 参数 $\mathbf{e}$ | 直接拼接 | 8 | $[W_{min}, W_{max}, t_f, l_f, h, d,$ 掌部标志, 掌部尺寸$]$，与 stage0.md §2.1 的 $G_{EEF}$ 对应 |
| 物体几何 $P_O$ | PointNet++ 类 encoder | 256 | $\{O\}$ 系工作点云，$N = 1024$；备选 SDF 采样编码（消融决定） |
| 近进方向 $\hat{a}$ | 标称基拼接 | 9 | $\hat{a}^O$ 与截面基 $\hat{e}_1, \hat{e}_2$（stage0.md §2.3 同一基），保证旋转等变性 |

**输出参数化**（关键设计）：

以标称系 $T_{nom}(\hat{a})$（由 $\hat{a}$ 与截面基 $\hat{e}_1/\hat{e}_2$ 确定，对给定输入是确定的、不依赖 teacher）为基准，网络输出 $K$ 个假设，每个为切空间扰动：

$$
\boldsymbol{\xi}_k = (\Delta t_k,\ \Delta\varphi_k) \in \mathbb{R}^6, \qquad
T_{TCP,k}^{O} = T_{nom}(\hat{a}) \cdot \exp(\hat{\boldsymbol{\xi}}_k)
$$

$\boldsymbol{\xi}$ 各分量物理语义清晰：垂直 $\hat{a}$ 的平面偏移（2）、Roll $\Delta\gamma$（1，绕 $\hat{a}$）、沿 $\hat{a}$ 深度（1）、俯仰/偏航修正（2）。**Roll 分量遵循项目硬约束：不使用 $\sigma = \pi$ 高斯；对称性信息（symmetry_class 下传）可缩窄其等效范围（stage0.md §6）**。

**生成头**：首选**条件扩散头**（DDPM/DDIM 框架，$\boldsymbol{\xi}$ 为噪声空间）；备选 MDN（消融）。多假设 $K$ 次采样天然覆盖多模态——这是对 stage1 因子化混合分布的学习版对应。

### 3.2 可微解析运动学层

stage1 公式的 PyTorch 实现，**零参数、零训练、精确可微**：

$$
T_{task,k} = f_{kin}\left(T_{TCP,k}^{W},\ d,\ \hat{a},\ X_e\right), \qquad
w_k^{*} = \text{clamp}\left(w_{geo,k},\ W_{min} + \delta_{pad},\ W_{max} - \delta_{pad}\right)
$$

包含：$P_{base} = p_c - d\hat{a}$（基座位置）、姿态合成（$\hat{a}$ + 开合轴 $X_e$，$X_e$ 由指对几何确定）、手指开度目标 $w^*$。所有坐标变换在 $\{W\}$ 系完成（项目硬约束）。

**不网络化的理由**（对原方案的修正）：EEF 固定安装时该映射是已知常值 SE(3) 变换；网络学已知函数 = 引入近似误差（误差恰在接触敏感区产生错误梯度）+ 训练成本 + 不可解释，纯负收益。

### 3.3 几何代价函数组

stage0 五项约束的软化版本 + 对齐项，对 $(T_{task,k}, P_O, \mathbf{e})$ 处处可微：

| 代价项 | 公式（hinge/relu 软化） | 硬约束来源 |
|---|---|---|
| 走廊穿透 | $\mathcal{L}_{cor} = \overline{\mathrm{relu}}\left(s_{max} - \mathrm{SDF}_{O \oplus \delta}\left(\mathrm{Sweep}(EEF_{open}, \hat{a}_k)\right)\right)$ | stage0 §4.3（膨胀 $\delta$ 版，仅此处用膨胀） |
| 宽度合法 | $\mathcal{L}_{w} = \overline{\mathrm{relu}}(W_{min} + 2\delta_{pad} - w_k) + \overline{\mathrm{relu}}(w_k - W_{max} + 2\delta_{pad})$ | stage0 §4.1（名义几何，$\delta_{pad}$ 唯一保守量） |
| 指物对齐 | $\mathcal{L}_{ali}$：指内侧面到接触点距离的 hinge | stage0 §4.5 |
| 对向性 | $\mathcal{L}_{anti} = \mathrm{relu}\left(-\mathbf{n}_1 \cdot \mathbf{n}_2 - \cos 2\theta_{fric}\right)$ | stage0 §4.2 |
| 包络深度 | $\mathcal{L}_{dep} = \mathrm{relu}(h_{min} - h_{eff,k})$ | stage0 §4.4 |
| 质心对齐 | $\mathcal{L}_{com} = \lVert d_{com,k} \rVert / \epsilon_{com}$ | stage0 §4.5 |

**课程设计**（源自 stage2 实测教训——零接触状态梯度消失）：

- **C1（粗对齐）**：$\mathcal{L}_{C1} = \mathcal{L}_{ali} + \mathcal{L}_{cor}$，先驱动假设进入接触邻域，解决冷启动零梯度；
- **C2（全约束）**：$\mathcal{L}_{C2} = \sum_i \lambda_i \mathcal{L}_i$（权重见 §10）。

**明确声明**：本代价组**不含动力学项**（摩擦滑落、提升稳定、扰动静默均为 stage2 的仿真级判定），几何收敛 ≠ 抓取成功——动力学 gap 由 §3.4 在环验证兜底。

### 3.4 Stage 2 在环验证与失败回流

**推理管线**：

1. 网络前向 → $K$ 个假设（按生成模型打分降序）；
2. 逐假设经解析层得 $T_{task,k}$、$w_k^{*}$，stage1 式预检（走廊/工作空间，硬筛）；
3. 通过预检者依次送 stage2 仿真判定（GraspDetector.detect + 提升确认，前向）；
4. **首过执行**；全败 → 按候选性/方向性分类回传（复用 stage0.md §8 协议）。

**失败回流（DAGGER 式）**：执行/验证失败样本 $(\text{输入}, \boldsymbol{\xi}_k, \text{失败原因}, \text{诊断量})$ 入池，供 §4.3 阶段消费——分布偏移的系统性修正来源。

## 4. 训练流程

### 4.1 阶段 T1：teacher 蒸馏 warm-start

- **数据**：§5 数据管线产出的正样本位姿集（stage2 验证通过的 $T_{TCP}^{O}$ 集合）；
- **损失**：标准扩散去噪损失（denoising score matching，作用于 $\boldsymbol{\xi}$）；
- **作用**：解决冷启动（初始网络 ≈ teacher 分布，不劣于 Plan A）+ 提供多模态标签（正样本集天然多模态，回避单峰平均陷阱）。

### 4.2 阶段 T2：几何代价端到端精调

- **损失**：$\mathcal{L} = \mathcal{L}_{DSM} + \lambda_{geo} \cdot \mathcal{L}_{C1/C2}$（课程从 C1 切 C2）；
- **可微性要点**：几何代价施加于网络的**单步去噪估计 $\hat{x}_0$**（DDPM 的 $x_0$-prediction 头天然可微），采样链路无需整体可微——规避 DDPM 采样不可微问题；
- **作用**：把 teacher 未覆盖的几何细节（点云 vs teacher 的基元/网格假设差异）修正进网络。

### 4.3 阶段 T3：采样–打分–回归闭环（stage2 在环）

- **流程**：网络条件分布 → 采 $M$ 个位姿 → 批量送 stage2 **前向**仿真打分（成功 = 力阈值 + 提升确认通过；分数可为 $\{-1, 0, +1\}$ 或连续奖励）→ 成功样本**加权最大似然回归**回网络（one-step policy improvement）；
- **关键性质**：仿真仅前向、不可微；梯度只存在于回归步——**完全规避 Genesis 1.3.3 的可微性限制**（§7）；
- **与 RL 的区别**：无 reward 反传、无 TD，直接加权回归，样本效率显著优于策略梯度；
- **失败回流消费**：§3.4 失败池样本以负权重/对比项进入回归目标；
- **上限突破**：T3 的信号来自真实仿真判定，学生可超越 teacher（teacher 只是初始化，不是天花板）。

## 5. 数据管线（teacher 批量标注）

| 环节 | 设计 |
|---|---|
| 物体来源 | 基元参数扫描（长方体/圆柱/球，尺寸随机化）+ 网格库子集（如 ABC 工程件），总量 $\sim 10^4$ |
| 方向采样 | 每物体 $\sim 10$ 个 $\hat{a}$（半空间均匀 + 偏置） |
| teacher 执行 | stage0 Top-K 候选 → stage1 分布 → stage2 批量并行仿真验证（Genesis 多环境） |
| 正样本 | 验证通过的 $T_{TCP}^{O}$ 集合 + stage1 分布参数（μ, Σ）+ symmetry_class |
| 负样本 | 失败候选及失败原因（corridor_collision / lift_fail / …），供 T3 对比项与失败分类器训练 |
| 规模 | $\sim 10^6$ 级样本（stage2 并行仿真摊薄成本） |
| 增广 | $\{O\}$ 系规范姿态对齐、对称类标签聚合（stage0 §6）、点云扰动（$\sigma$ 与 stage0 §7 感知误差模型一致） |

## 6. 接口定义

**输入**（与 stage0.md §2.1 输入对齐）：

```json
{
  "eef_params":   {"W_min": 0.0, "W_max": 0.08, "t_f": 0.01, "l_f": 0.06,
                   "h": 0.04, "d": 0.08, "palm": null},
  "object_pointcloud": "[N,3] array, {O} 系",
  "approach":     "[ax, ay, az], {W} 系单位向量"
}
```

**输出**（与 stage1.md §2.2 消费方对齐；所有几何量 {O} 系）：

```json
{
  "hypotheses": [
    {"xi": [dx, dy, dz, droll, dpitch, dyaw],  // 切空间扰动，相对 T_nom(â)，平移在前
     "T_tcp_O": "[4,4]",                        // 合成位姿（{O} 系）
     "w_star": 0.045,                            // 手指开度目标
     "score": 0.87}                              // 生成模型打分，降序
  ],
  "symmetry_class": "C2",
  "fallback": {"reason": null}                   // 全败时按 stage0 §8 协议回填
}
```

注：本方案不显式输出接触点对 $(p_1, p_2)$（网络隐式决定抓取构型），stage1 的 p₁→p₂ 方向契约（stage0.md §2.3）在此不适用；可选输出接触注意力热图用于可解释性，非接口必需。

## 7. 引擎约束与已排除路线（Genesis 1.3.3 实测）

以下路线经本仓库系统实测（stage2.md v1.2 及开发记录），**明确排除**，避免重蹈：

| 路线 | 实测结论 | 后果 |
|---|---|---|
| 位姿经 `scene.reset()` 注入并回传梯度 | 初始状态注入无梯度路径 | 端到端"位姿→仿真"梯度链路不存在 → T3 改采样–打分–回归 |
| PD 位置目标可微化 | `control_dofs_position` 回传显式抛异常 | 可微控制入口仅 `control_dofs_force`（力参数，低维） |
| 接触力 loss 端到端 | `get_contacts()`/力传感器返回 detached 张量 | 接触力无梯度 → stage2 用力控 + 几何穿透代理（该技巧不适用于位姿级端到端） |
| 可微查询面 | 仅 `scene.get_state()` 族（qpos/links_pos 等） | T2 的几何代价基于 links_pos/SDF 可微量构建 |

另：zerocopy 路径的 int32→int64 索引崩溃及 site-packages 补丁见 `doc/genesis_zerocopy_int32_bug.md`（本方案数据管线的批量仿真同样依赖该补丁环境）。

## 8. 评估与验收标准

| 指标 | 定义 | 验收线 |
|---|---|---|
| Top-K 通过率 | K 个假设中 ≥1 个通过 stage2 判定的比例 | ≥ Plan A 基线（同物体集、同 $\hat{a}$ 集） |
| Top-1 通过率 | 首假设通过率 | T3 结束后 ≥ Top-K 的 70% |
| 推理延迟 | 网络前向 + 解析层（GPU） | ≤ 50 ms（对照 stage0+1 搜索全程） |
| 泛化衰减 | held-out 物体集 Top-K 相对训练集的下降 | ≤ 10 个百分点 |
| 蒸馏保真 | T1 后网络分布与 teacher 分布的 KL | KL ≤ 阈值（标定后填入 §10） |
| 闭环收益 | T3 相对 T1 的 Top-K 提升 | ≥ 5 个百分点 |

## 9. 风险与缓解

| 风险 | 缓解 |
|---|---|
| 多模态平均（回归范式结构缺陷） | 扩散头多假设输出；T1 蒸馏目标为位姿集合而非单点 |
| 冷启动零梯度（stage2 实测先例） | T1 蒸馏 warm-start + T2 课程 C1 先行 |
| 几何–动力学 gap | stage2 在环兜底；T3 用真实判定信号训练 |
| 学生上限被 teacher 封顶 | T3 信号来自仿真而非 teacher；teacher 仅初始化 |
| 分布偏移（部署与数据分布不一致） | DAGGER 式失败回流（§3.4） |
| 点云编码对感知噪声敏感 | 数据增广噪声与 stage0 §7 感知误差模型一致 |
| 扩散采样延迟 | DDIM 少步采样（10 步）+ K 假设批量并行 |

## 11. 方法选型总结

| 设计点 | 选择 | 放弃方案及其失败模式 |
|---|---|---|
| 生成头 | 条件扩散（多假设） | 单峰回归（多模态平均陷阱）；MDN（备选消融） |
| 运动学层 | 可微解析层 | 网络化运动学（近似误差毒化梯度、纯负收益） |
| 几何训练 | 蒸馏 + 代价端到端（$\hat{x}_0$ 可微路径） | 纯代价从零训练（零梯度启动） |
| 动力学训练 | 采样–打分–回归 | 端到端可微仿真（Genesis 1.3.3 无位姿梯度路径）；RL（样本效率低） |
| 最终判定 | stage2 在环（前向） | 纯几何代价阈值（动力学 gap 无兜底） |
| 与 Plan A 关系 | teacher + 验证器 | 完全替代（放弃解析可解释性与零训练基线） |
