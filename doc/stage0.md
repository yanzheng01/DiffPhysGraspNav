以下将几何匹配整理为独立的第 0 阶段方案文档，与第一阶段（解析位姿计算）、第二阶段（数值采样精调）形成完整的流水线接口。

# 抓取规划第 0 阶段方案：几何匹配
## 1. 方案定位与概述
本方案是“由粗到精”三阶段抓取规划流水线的最前端环节。其任务是在给定物体几何、EEF 接触参数和近进方向的条件下，**在物体表面搜索与夹爪接触特征兼容的候选接触区域**，为第一阶段的解析位姿计算提供几何锚点。
```
┌─────────────────┐    ┌──────────────────┐    ┌──────────────────┐
│ 第0阶段: 几何匹配 │ →  │ 第1阶段: 解析位姿  │ →  │ 第2阶段: 采样精调  │
│ 输出接触锚点      │    │ 计算基准位姿分布   │    │ 局部采样+质量评估  │
└─────────────────┘    └──────────────────┘    └──────────────────┘
```
**数学本质**：一个带约束的表面搜索问题：
$$
\text{Find } (\vec{p}_1, \vec{p}_2) \in \partial O \times \partial O, \quad
\text{s.t. } \mathcal{C}_{width},\ \mathcal{C}_{antipodal},\ \mathcal{C}_{corridor},\ \mathcal{C}_{clearance},\ \mathcal{C}_{com}
$$
## 2. 输入与输出定义
### 2.1 输入
| 符号 | 含义 | 类型 / 默认值 |
|---|---|---|
| $G$ | 物体几何表示（基元 / Mesh / 点云 / SDF） | 必选 |
| ${}^{W}T_{O}$ | 物体在世界系下的位姿（若由感知估计，误差注入第1阶段协方差） | 必选 |
| $\hat{a}$ | 近进方向（世界系单位向量） | 必选 |
| $[W_{min}, W_{max}]$ | 夹爪有效夹持宽度范围 | 必选 |
| $h$ | 指面深度（包络长度） | 必选 |
| $G_{EEF}$ | EEF 手指简化几何（指厚 $t_f$、指长 $l_f$，可选掌部盒；走廊校验 §4.3 用） | 必选 |
| $\theta_{fric}$ | 等效摩擦锥半角 | 默认 $15°$ |
| $K$ | 保留候选数 Top-K | 默认 $K=10$ |
### 2.2 输出（对接第一阶段接口）
每个候选的完整几何描述：
```json
{
  "p1": [x, y, z],          // 接触点1（物体坐标系）
  "p2": [x, y, z],          // 接触点2（{O} 系；p1→p2 = 开合轴正方向，顺序契约见 §2.3）
  "p_center": [x, y, z],    // 接触区域中心 pc（{O} 系）
  "normal": [nx, ny, nz],   // 接触面法向 n̂（{O} 系，p₁ 侧、指向物体外）
  "approach": [ax, ay, az], // 本候选的局部修正近进方向（{O} 系）
  "grip_width": w,          // ||p1 - p2||
  "envelope_depth": h_eff,  // 有效包络深度
  "score": s,               // 几何评分 ∈ [0, 1]
  "symmetry_class": id      // 对称等价类（用于跨阶段去重）
}
```

**坐标系统一**：所有几何向量输出（`p1`、`p2`、`p_center`、`normal`、`approach`）均在物体坐标系 $\{O\}$ 下表达，与 stage1.md §2.2 的输入约定直接对齐（该阶段统一先变换至 $\{W\}$ 再计算）。注意本阶段输入的 $\hat{a}$ 为 $\{W\}$ 系单位向量，输出 `approach` 为经局部修正并变换至 $\{O\}$ 系的结果：$\hat{a}_{cand}^{O} = R_{W}^{O}\,\hat{a}_{cand}^{W}$；标量字段（`grip_width`、`envelope_depth`、`score`）与坐标系无关。

### 2.3 接触点对方向约定（接口契约）
第一阶段（stage1.md §3.2）以 $\vec{p}_1 \to \vec{p}_2$ 连线在垂直于 $\hat{a}$ 平面上的投影为开合轴正方向 $\vec{X}_e$。若本阶段输出的点对顺序不确定（同一候选两次生成时顺序相反），$\vec{X}_e$ 将相差 $180°$，导致几何先验模式下 Roll 分布基准不一致、跨阶段候选去重失效。因此所有路径（A/B/C）统一遵守以下确定性规则：

1. **截面基**：$\hat{e}_1 = \mathrm{normalize}\big(\hat{z}_O - (\hat{z}_O \cdot \hat{a})\hat{a}\big)$（$\{O\}$ 系 Z 轴单位向量向垂直于 $\hat{a}$ 的平面投影；投影退化时改用 $\hat{x}_O$），$\hat{e}_2 = \hat{a} \times \hat{e}_1$；
2. **方向角**：令 $\Delta\vec{p} = \vec{p}_2 - \vec{p}_1$，要求其在截面基下的方向角 $\theta \in [0, \pi)$，即 $\Delta\vec{p} \cdot \hat{e}_1 > 0$，或 $\Delta\vec{p} \cdot \hat{e}_1 = 0$ 时 $\Delta\vec{p} \cdot \hat{e}_2 > 0$。

该规则与 §3.2 切片法的角度参数化共享同一截面基（$\hat{u}(\theta) = \cos\theta\,\hat{e}_1 + \sin\theta\,\hat{e}_2$），实现天然一致。

### 2.4 对第一阶段 Roll 分布模式的决定作用
本阶段是否输出有效接触点对，直接决定第一阶段（stage1.md §4.2）的开合轴来源与 Roll 维分布形态：

| 本阶段输出 | 第一阶段开合轴来源 | Roll 维分布 |
|---|---|---|
| 有效 $(\vec{p}_1, \vec{p}_2)$，且连线与 $\hat{a}$ 投影非退化 | 接触点对投影（几何先验） | 小方差高斯 $\mathcal{N}(0, \sigma_\gamma^2)$，$\sigma_\gamma \approx 0.05 \sim 0.1\,\mathrm{rad}$ |
| 无点对，或投影退化（连线接近 $\hat{a}$） | 参考向量法（回退） | 均匀分布 $\mathcal{U}[-\pi, \pi)$ |

接触点对因此是本阶段最核心的下传量：它将 Roll 维不确定性从全周均匀压缩到小方差邻域。Top-K 输出应优先保留投影非退化的候选；仅当全部候选退化时，才允许下游进入回退模式。

## 3. 核心匹配算法
按物体表示分三条路径，**推荐以截面切片法为主线**。
### 3.1 路径 A：解析基元（CAD 模型）
当物体可分解为参数基元时，匹配退化为特征枚举查询：
| 基元 | 匹配策略 | 接触点解析解 |
|---|---|---|
| 长方体 | 枚举平行表面对，校验法向相反、间距 ∈ $[W_{min}, W_{max}]$ | 面上距质心投影最近的点对 |
| 圆柱体 | 取垂直于 $\hat{a}$ 投影的径向弦 | 弦端点，$\hat{n}$ 沿径向 |
| 球体 | 任意对径点对 | $\vec{p}_c$ = 球心 + $r\hat{n}$ 偏置 |
| 一般二次曲面 | 沿 $\hat{a}$ 截面求宽度函数 $w(\theta)$ | $w(\theta)\in[W_{min},W_{max}]$ 的弦段 |
**接触点位置确定**：平行面对抓时接触点在面内的位置由质心对齐约束（§4.5）确定——取各面上距质心（投影到面）最近的点，使夹持力矩最小；沿 $\hat{a}$ 的深度优先取过质心的切片（力臂最小），最终由走廊检查（§4.3）与包络深度（§4.4）筛定。球体等本质上欠定的情形（任意对径点对等效）以 §2.3 截面基参数化取确定解。各基元枚举的接触点顺序统一遵循 §2.3 方向约定。计算量极低，适用于结构化工业件。
### 3.2 路径 B：Mesh 表示 —— 截面切片法（主方法）
与近进方向 $\hat{a}$ 天然耦合的匹配方案：
```text
算法: SliceMatch
输入: mesh M, 近进方向 a, 宽度范围 [W_min, W_max], 步长 Δt
输出: 候选接触集合 S
1  计算深度区间: 沿 a 方向求 M 的包围盒投影, 得切片区间 [t0, t1]
2  for t ← t0 to t1 step Δt do
3      Π_t ← 过点 t·a、法向为 a 的切片平面
4      P_t ← M 与 Π_t 的截面多边形 (逐三角面求交, 环路拼接)
5      for 每个方向 θ ∈ [0, π) step Δθ do
6          (c₂, c₁) ← P_t 沿 u(θ) 方向的支撑弦对（c₂ 为 +u 侧极值点，c₁ 为 −u 侧极值点；u(θ) 见 §2.3）
7          w ← ||c₁ - c₂||
8          if W_min ≤ w ≤ W_max then
9              n1, n2 ← c₁, c₂ 处边界外法向
10             if n1·n2 < -cos(2θ_fric) and 连线穿过 P_t 内部 then
11             S ← S ∪ {(c₁, c₂, midpoint, -n1, t)}   // p₁=c₁, p₂=c₂，顺序契约见 §2.3
12 for s ∈ S do
13     if not CorridorCheck(s) then 移除 s        // 见 §4.3
14     if not DepthCheck(s) then 移除 s           // 见 §4.4
15 return Score_Sort(S) 取 Top-K
```
**关键实现细节**：
- **宽度函数**：凸截面用旋转卡壳 $O(n)$；非凸截面先做凸包分解，凹段直接排除（凹处夹持不稳定）；
- **切片深度选择**：靠近质心侧力臂小、稳定性高，但须通过走廊检查（避免手指沿 $\hat{a}$ 进入时与其他部位干涉）；
- **步长建议**：$\Delta t$ 取指面深度 $h$ 的 $1/3 \sim 1/2$，避免相邻切片候选冗余。
### 3.3 路径 C：点云 / SDF（感知输入）
1. **法向估计**：对点云做局部 PCA 估计 $\hat{n}_i$（邻域半径取夹持宽度的 5~10%）；
2. **Antipodal 点对采样**：构建 KD-tree，查询满足 $\hat{n}_i \cdot \hat{n}_j < -\cos(2\theta_{fric})$ 且间距 ∈ $[W_{min}, W_{max}]$ 的点对，并校验连线方向与 $\hat{a}$ 的夹角一致（点对顺序遵循 §2.3 方向约定）；
3. **SDF 走廊检查**：构造有符号距离场 $f(x)$，沿 $\hat{a}$ 检查手指扫掠走廊内 $f(x) \geq \delta_{clear}$，仅接触区允许 $f=0$；
4. 备选：局部拟合超二次曲面后降级到路径 A。
## 4. 约束校验模块
所有路径产出的候选统一通过以下五项校验：
### 4.1 宽度约束
$$
W_{min} + 2\delta_{pad} \leq \|\vec{p}_1 - \vec{p}_2\| \leq W_{max} - 2\delta_{pad}
$$
$\delta_{pad}$ 为指面软垫压缩量；**优先夹紧行程裕量大的候选**（开度越小，剩余夹紧行程越充足，评分定义见 §5）。宽度、对向、深度、质心四项校验均在**名义几何**上进行，$\delta_{pad}$ 是其中唯一的保守量；§7 的 Minkowski 膨胀 $\delta$ **仅用于走廊/干涉检查**（§4.3 及路径 C 的 SDF 走廊），不与本约束叠加——两者数学上近似等效（膨胀 $\delta$ ≈ 宽度范围收缩 $2\delta$），叠加会导致双重保守、将边缘合格候选错误排除。
### 4.2 对向 / 摩擦锥约束
$$
\hat{n}_1 \cdot \hat{n}_2 \leq -\cos(2\theta_{fric})
$$
保证夹持力可分解出足够摩擦分量抵抗重力与扰动。
### 4.3 进入走廊约束（关键校验）
手指沿 $\hat{a}$ 平移进入时，其扫掠体不得与物体相交：
$$
\left(\text{Sweep}(EEF_{open}, \hat{a}) \cap O\right) \setminus \text{ContactRegion} = \emptyset
$$
**扫掠体构建**（由 §2.1 的 $G_{EEF}$）：两根指盒（截面 $t_f \times l_f$）以 $W_{max}$ 开度对称布置，从接触深度沿 $-\hat{a}$ 平移至完全后退位置的扫掠并集；掌部盒（若提供）自 TCP 位同步扫掠。无 $G_{EEF}$ 时降级为双平板近似（开度 $W_{max}$、零厚度），仅保留平面内干涉筛查。此条排除“接触点合法但物理上进不去”的候选（如深凹槽底部）。
### 4.4 包络深度约束
接触区沿接近方向 $\hat{a}$（指长方向）的包络深度 $h_{eff} \geq h_{min}$（默认 $h_{min} = 0.3h$），避免仅指尖边缘接触导致的抗旋转能力不足。
### 4.5 质心对齐约束
两接触点连线中点与质心在接触平面投影的距离：
$$
\text{dist}\left(\vec{p}_c,\ \text{proj}_{\perp\hat{n}}(\vec{p}_{com})\right) \leq \epsilon_{com}
$$
减小夹持后的力矩翻转风险。
## 5. 几何评分函数
通过校验的候选用轻量解析评分排序（不做物理仿真，保持第 0 阶段轻量）：
$$
Score = w_1 \cdot \underbrace{\frac{W_{max} - \|\vec{p}_1-\vec{p}_2\|}{W_{max} - W_{min}}}_{\text{夹紧行程裕量}} + w_2 \cdot \underbrace{\frac{h_{eff}}{h}}_{\text{包络深度}} + w_3 \cdot \underbrace{\left(1 - \frac{d_{com}}{d_{max}}\right)}_{\text{质心对齐}} + w_4 \cdot \underbrace{S_{sym}}_{\text{对称性奖励}}
$$
**默认权重**：$w_1 = 0.4,\ w_2 = 0.25,\ w_3 = 0.25,\ w_4 = 0.1$，可按任务调整。行程裕量项在 $w = W_{min}$ 时取 1、$w = W_{max}$ 时取 0，取值域 $[0,1]$，与 §4.1"优先夹紧行程裕量大的候选"保持一致。

**质心项归一化**：$d_{com}$ 为 §4.5 的质心偏移距离，$d_{max} := \epsilon_{com}$（§4.5 的容差）——通过校验的候选满足 $d_{com} \leq \epsilon_{com}$，故质心项取值域 $[0,1]$，在约束边界处取 0。

**对称性奖励定义**：$S_{sym} = \min\left(1,\ \frac{n_{sym}-1}{3}\right) \in [0,1]$，其中 $n_{sym}$ 为物体绕近进方向 $\hat{a}$ 的旋转对称阶（对称群 $Aut(O)$ 中绕 $\hat{a}$ 旋转子群的阶，见 §6；连续对称如圆柱记 $n_{sym}=\infty$）。无对称（$n_{sym}=1$）取 0，二重取 $1/3$，三重取 $2/3$，四重及以上（含连续对称）取 1。物理含义：对称阶越高，Roll 采样误差落入等效抓取构型的概率越大，抓取对姿态误差越鲁棒。
## 6. 对称性压缩搜索
利用物体对称群 $Aut(O)$ 去重，等效候选只评估一次：
- **旋转对称**（圆柱）：仅匹配一个径向角度，其余由对称生成；
- **镜面对称**（盒体）：枚举半个空间；
- **Roll 等效类**：设绕 $\hat{a}$ 的旋转对称阶为 $n_{sym}$（连续对称如圆柱 $n_{sym} = \infty$）。离散对称下 Roll 维等效类共 $n_{sym}$ 个（等效周期 $2\pi/n_{sym}$）；连续对称下 Roll 维完全退化（任意 $\gamma$ 等效）。
- **与第 1/2 阶段衔接**：等效类信息随候选的 `symmetry_class` 字段下传，作用于第一阶段的 Roll 分布定义——回退模式的均匀范围可由 $[-\pi, \pi)$ 缩减为 $[-\pi/n_{sym},\ \pi/n_{sym})$（仍为均匀分布，且范围小于 $2\pi$，无角度环绕问题）；几何先验模式的 $\sigma_\gamma$ 保持不变（对称性提供的是误差容限而非集中先验）；连续对称时 Roll 维可坍缩为确定值（$\sigma_\gamma \to 0$）。第二阶段相应缩减 Roll 采样范围，且仍不得依赖 Roll 基准值的连续性。
## 7. 鲁棒性处理
| 措施 | 实现 | 目的 |
|---|---|---|
| 几何膨胀 | 物体做 Minkowski 和 $O \oplus B_\delta$（$\delta$ = 感知误差上界），**仅用于走廊/干涉检查**（§4.3），不进入宽度约束（分工说明见 §4.1） | 对模型误差保守安全且不双重保守 |
| 法向平滑 | 邻域加权平均法向，避开高曲率突变区 | 点云边缘法向不可靠 |
| Top-K 保留 | 不做早停，保留 $K$ 个候选下发 | 单一候选失效不导致整体失败 |
| 误差传递 | ${}^{W}T_O$ 的感知误差注入第 1 阶段 $\boldsymbol{\Sigma}$（切空间 6 维，平移在前）的平移块：$\boldsymbol{\Sigma}_{trans} \leftarrow \boldsymbol{\Sigma}_{trans} + \mathrm{diag}(\sigma_x^2, \sigma_y^2, \sigma_z^2)$，$\sigma_i$ 为感知平移标准差；姿态误差角经一阶传播并入 $\boldsymbol{\Sigma}_{rot}$ | 不确定性显式跨阶段传递 |
## 8. 与第一阶段的失败回传闭环
第一阶段（stage1.md §3.4）预检失败时不输出无效基准，而是返回失败原因及诊断量（如 $P_{base}$ 坐标、接近路径几何），请求更换近进方向或接触区域。本阶段作为接触区域提供者，约定以下调度协议：

1. **下发顺序**：Top-K 候选按 `score` 降序下发，第一阶段逐个尝试（每候选独立完成解析计算与预检）；
2. **候选性失败**：失败诊断量随候选变化（仅该候选的接近路径碰撞 / 仅该 $P_{base}$ 不可达）→ 弃用该候选，尝试下一候选；
3. **方向性失败**：多数候选失败且原因同源（如所有接近路径均扫过支撑面、工作空间整体不可达）→ 本轮 Top-K 全部作废，向上游回传失败原因与诊断量汇总，请求更换近进方向 $\hat{a}$ 后重新运行本阶段；
4. **回传格式**：`{candidate_id, reason ∈ {corridor_collision, workspace_unreachable, …}, diagnostics}`，供本阶段归因分类与上层重规划消费。

该协议保证"预检失败 → 更换候选/方向"形成显式闭环，而非静默依赖后续采样纠正（与 stage1.md §3.4 失败处置约定一致）。

## 9. 默认参数表
| 参数 | 符号 | 默认值 | 说明 |
|---|---|---|---|
| 切片步长 | $\Delta t$ | $h/3$ | 避免候选冗余 |
| 角度采样步长 | $\Delta\theta$ | $5°$ | 离散方向扫描用；凸截面优先旋转卡壳（顶点驱动、精确，无需 $\Delta\theta$） |
| 摩擦锥半角 | $\theta_{fric}$ | $15°$ | 保守取值（钢-橡胶接触可放宽） |
| 走廊净空 | $\delta_{clear}$ | $2\,\text{mm}$ | 与定位精度匹配 |
| 最小包络深度 | $h_{min}$ | $0.3h$ | 指面深度的 30% |
| 质心偏移容差 | $\epsilon_{com}$ | $0.2\,W_{max}$ | — |
| 保留候选数 | $K$ | $10$ | 下游逐个尝试 |
## 10. 方法选型总结
| 物体表示 | 推荐路径 | 计算量 | 适用场景 |
|---|---|---|---|
| CAD 基元 | A：特征枚举查询 | 极低 | 结构化工业件 |
